Hermes

2026 to now · running

An operations agent running on a private VPS, built on the open-source Hermes Agent framework. It handles the recurring work across my companies. I run it from Telegram, one thread per subject, with memory that persists across months.

Twenty-two scheduled jobs in production. Nine cover Decato: Search Console pulls, an indexation watchdog, technical checks, a content backlog, a weekly operations report, lead digests and conversion alerts. The rest draft the weekly investor update, sweep stale follow-ups, run a daily finance check-in, and maintain the system itself through a nightly backup and a guarded weekly update.

Teaching it

The first session in Yerevan drew thirty people and five volunteer mentors. AI9 Startup Campus hosted the next in May 2026, with attendees required to arrive with a server provisioned and SSH working.
