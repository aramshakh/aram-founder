Agent operations

2026 to now · running

Hermes is an open-source agent framework from Nous Research. I did not write it. What is mine is the setup running on it: a private VPS that handles the recurring work around Decato and around me, driven from Telegram, one thread per subject, with memory that persists across months.

Twenty-two scheduled jobs in production, in three groups. Growth: nine jobs on Decato — Search Console pulls, an indexation watchdog, technical checks, a content backlog, a weekly operations report, lead digests and conversion alerts. Money: the weekly investor update draft, a sweep of stale follow-ups, a daily finance check-in. Upkeep: a nightly backup and a guarded weekly update of the system itself.

Teaching it

The first session in Yerevan drew thirty people and five volunteer mentors. AI9 Startup Campus hosted the next in May 2026, with attendees required to arrive with a server provisioned and SSH working.
